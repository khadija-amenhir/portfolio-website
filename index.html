Security

Man-in-the-Middle attack (ARP poisoning)

Lab on an isolated network with Kali Linux as the attacker and a Windows 8.1 client as the victim. I poisoned the victim’s ARP table with Ettercap to sit between it and the gateway, then captured and analysed the traffic with tcpdump.

How it went
  1. Built an isolated network with attacker and victim machines in VMware.
  2. Exploited ARP’s lack of authentication with Ettercap to redirect the victim’s traffic.
  3. Captured the traffic with tcpdump and read IP addresses, ports and TCP flags.
  4. Concluded why HTTPS and DHCP Snooping are essential defences.
  • Kali Linux
  • Ettercap
  • tcpdump
  • VMware
Security

Penetration test on Metasploitable

Full pentest of a deliberately vulnerable machine from Kali Linux, following the classic methodology. I exploited the backdoor in vsftpd 2.3.4 with Metasploit and obtained a remote root shell.

How it went
  1. Reconnaissance: Nmap ping scan to find the target on the network.
  2. Scan: full SYN scan of all ports revealed about twenty open services, a sign of poor hardening.
  3. Exploitation: spotted vsftpd 2.3.4 on port 21 and used the matching Metasploit module.
  4. Post-exploitation: explored the compromised system as root.
  5. Report: documented the flaws and recommendations (update services, close unused ports).
  • Nmap
  • Metasploit
  • Kali Linux
  • Pentesting

Apache web server & virtual hosts

Installed and configured Apache2 on Debian (VirtualBox) and hosted several sites on one server using the three virtual hosting methods, tested from Debian, Windows and Kali clients.

How it went
  1. Network setup with two adapters: Bridged and Host-only, checked with ping.
  2. Installed Apache2 and prepared one folder per site in /var/www.
  3. Virtual hosts by IP address, by port (80 and 8080), and by domain name using the hosts file.
  4. Final test of all three setups from a remote Kali client.
